# Kort beskrivning
### Projektet går ut på att skapa en ny och moderniserad webbplats för Racebutiken, ett företag som säljer produkter och tillbehör för folkrace. Webbplatsen består av tre sidor: en startsida, en produktsida och en kontaktsida. Besökare kan utforska sortimentet, söka efter produkter, lägga varor i en varukorg och kontakta företaget via ett formulär. Webbplatsen har utvecklats med HTML, CSS och JavaScript med fokus på användarvänlighet, tydlig design och responsivitet.
